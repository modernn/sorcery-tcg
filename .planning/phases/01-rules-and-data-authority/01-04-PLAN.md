<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selected bundle path -> filesystem | Untrusted paths and symlinks can escape the authority root. |
| manifest/reference graph -> validated bundle | Malicious JSON, graph cycles, substitution, and tampering can masquerade as official authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-16 | Tampering / DoS | recursive bundle parsing | mitigate | Strict bounded parsing plus aggregate byte/file/depth/ref/diagnostic caps; test oversized/deep/cyclic cases. |
| T-01-17 | Tampering / Elevation | `resolveWithinAuthorityRoot` | mitigate | Reject absolute/traversal paths and verify normalized realpaths/symlinks remain under the configured root before reads. |
| T-01-18 | Spoofing | official sources/precedence | mitigate | Allowlisted official HTTPS records, explicit authority class/effective date/scope, reviewed acquisition, exact hashes, unsupported ambiguity. |
| T-01-19 | Tampering | source/artifact references | mitigate | Recompute every byte/content hash, validate expected root ID/hash, reject missing refs and cycles. |
| T-01-20 | Information disclosure / legal | stored media/raw corpus | mitigate | Enforce legal/storage status and deny PDF/image/unapproved raw database bytes during recursive validation. |
| T-01-SC | Tampering | package installs | mitigate | Use only Plan 01's audited lockfile; validator uses Node built-ins and existing Zod only. |
</threat_model>
