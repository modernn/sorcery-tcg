<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local raw card bytes -> strict normalizer | Malicious or malformed JSON can exhaust resources or conceal duplicate/lost records. |
| supplied source metadata -> canonical card provenance | A caller can falsely label bytes as official or permitted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Tampering / DoS | `normalizeCards` input | mitigate | Reuse bounded duplicate-aware parsing and strict schemas; enforce cardinality/ID uniqueness and deterministic diagnostic caps. |
| T-01-12 | Tampering | input path | accept | This pure module accepts bytes, not paths; Plan 04/05 own confinement for filesystem callers. |
| T-01-13 | Spoofing | source metadata | mitigate | Require a strict reviewed `SourceRecord` and bind its byte hash; Plan 06 supplies the human authenticity/permission review. |
| T-01-14 | Tampering | normalized snapshot | mitigate | Canonicalize, hash, freeze/copy, and revalidate the output artifact before return. |
| T-01-15 | Information disclosure / legal | raw card fixtures/output | mitigate | Tests use synthetic/minimal facts; the normalizer does not persist bytes, and Plan 06/07 gate official derivative publication. |
| T-01-SC | Tampering | package installs | mitigate | Use only the locked Plan 01 dependencies; add no normalization package. |
</threat_model>
