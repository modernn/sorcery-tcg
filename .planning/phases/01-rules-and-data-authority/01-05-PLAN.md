<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command arguments/local input tree -> authority library | Malicious arguments/files can trigger traversal, DoS, or substitution. |
| validated temporary revision -> published immutable revision | Partial or tampered output must not become visible. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-21 | Tampering / DoS | command input JSON | mitigate | Reuse strict bounded schemas and graph caps; read only explicitly named files; return bounded sorted diagnostics. |
| T-01-22 | Tampering / Elevation | input/output paths | mitigate | Reuse realpath confinement, reject absolute/traversal/symlink escape, and delete only the verified temp target on failure. |
| T-01-23 | Spoofing | local source bytes | mitigate | Bind reviewed source metadata to exact raw hashes and require Plan 06 authenticity/permission checkpoint before official publication. |
| T-01-24 | Tampering / Repudiation | temporary/published artifacts | mitigate | Revalidate expected bundle ID/hash before atomic rename; refuse overwrite; emit deterministic machine-readable result. |
| T-01-25 | Information disclosure / legal | bundle publisher | mitigate | Storage policy blocks PDFs/images/unapproved raw corpora; commands contain no acquisition or bypass flag. |
| T-01-SC | Tampering | package installs | mitigate | Use Plan 01's locked approved packages; add no CLI/filesystem library. |
</threat_model>
