<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixed publisher response -> staged private source | Shell, truncation, malformed data, or hidden metadata can masquerade as complete authority. |
| existing primary/backup roots -> replacement revision | Previously acquired bytes could bypass strengthened completeness checks unless both roots are revalidated offline and immutably. |
| private collector -> terminal/transcript | Exceptions and returned objects can disclose private locators and lock fields. |
| PowerShell -> Node verifier child | A blocked pipe or hung child can deny completion and strand owned outputs. |
