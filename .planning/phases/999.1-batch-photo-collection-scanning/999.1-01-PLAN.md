# Phase 999.1 Plan 01: Private Photo Scan and Reconciliation Slice

## Goal

Turn user-supplied binder-page or tabletop photos into a deterministic reviewed count proposal without changing simulator or rules-engine behavior.

## Scope

- Keep photos, visual references, reviews, reports, and saved collections under ignored `.local/collection/` storage.
- Validate card identities and printing slugs against the existing private normalized authority catalog.
- Detect and rectify card-shaped regions locally with a bounded deterministic OpenCV helper.
- Match detections only against reviewer-confirmed, user-supplied private reference images.
- Auto-confirm only matches that pass both an absolute confidence threshold and a best-versus-second margin.
- Count confirmed duplicates by canonical card, printing slug, and finish.
- Emit unresolved detections for human review and refuse collection publication until every detection is confirmed.
- Reconcile confirmed counts with a saved collection in explicit `add` or `replace` mode and write a new collection file.

## Boundaries

- No official artwork is acquired, committed, packaged, uploaded, or redistributed.
- No photo or private catalog byte is sent over the network.
- No LLM defines recognition, counting, review status, or reconciliation.
- The normalized authority artifact remains unchanged; finish labels exist only in the ignored local reference catalog.
- OCR and a browser review UI are deferred. Add either only when private reference matching plus JSON review is measurably insufficient.

## Acceptance checks

- A synthetic photo containing separate card-shaped regions produces stable reading-order detections.
- A confirmed private reference identifies repeated cards and produces an exact duplicate count.
- Ambiguous or unknown matches remain unresolved and do not change the proposed collection.
- Review decisions are validated against the pinned authority catalog before reconciliation.
- Collection output is written only when all detections are resolved.
- `pnpm verify` passes and the diff contains no simulator or rules-engine changes.
