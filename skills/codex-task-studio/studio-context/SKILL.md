# Context discipline

Keep always-loaded instructions focused on non-negotiables and routing. Move detail to a linked reference only when it is needed for a subset of work; preserve moved wording and evidence rather than deleting it. Do not impose automatic aggressive clipping or arbitrary byte limits. Inspect relevant files before changing them, keep each skill narrowly triggered, and disclose detail progressively. Do not pretend skill frontmatter enforces model, tools, or permissions; set model and effort in task creation and constrain tools in the brief where enforcement is unavailable.
