# Studio journal

Append a concise entry to the existing journal at run close-out. Include run/task IDs; selected model and effort; exact target/base hashes; outcome and findings with severity; gate results; remote hash when one exists; archived task IDs; unresolved scope; and the next action. Record token/cost telemetry only when actual telemetry is available; otherwise use unavailable/null, never estimates. Preserve useful history; do not rewrite old evidence to imply freshness. Keep journal location and format consistent with the existing project ledger.
